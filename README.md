# Paçisi

Kabukları at, haçın etrafını ortağınla dolaş! Hindistan'ın klasik haç ve daire yarışı (Ludo'nun atası): 6 kabuk, lütuf atışları, 12 kale karesi, karşılıklı ortaklar. Yapay zekâ rakiplere karşı ya da aynı cihazda 2–4 kişi; çevrimiçi masada boş koltuklara bot oturur. 100.000 bölüm. Masa Oyunları merkez uygulamasının oyunu; ortak motor: masa-motoru.
